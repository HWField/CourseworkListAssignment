My program fully implements the open-ended coursework specification converting all specified data types from Decimal to Binary and Binary to Decimal including parsing structured input. Validation checks numeric ranges, argument syntax and for structure definitions, reporting "Input error." for detected errors. Running with no arguments runs tests coverage. Shared parsing, formatting and conversion functions reduce code duplication (DRY). Only libraries defined in C11 standard are used. Tests assume 8-bit char, 32-bit int, and 64-bit long / double. Structured input parsing is limited to all decimal or all binary values (consistent with examples) as combinations cause ambiguous results.
